🖨️ Khối 8: Cơ Chế Căn Chỉnh & Tác Động Máy In Kim Khổ A5 (@media print)

Dot Matrix Printer Engineering
📄 Code CSS Định Tuyến Máy In (print.css) 
/* 1. TRIỆT TIÊU LỀ MẶC ĐỊNH & NHẢ CHỌN NGANG/DỌC */
@page {
  size: auto;
  margin: 0mm !important; /* Xóa lề để triệt tiêu Header/Footer rác của browser */
}

/* 2. CĂN CHỈNH TỌA ĐỘ VẬT LÝ KHỔ A5 NGANG */
.print-page {
  width: 100% !important;
  /* Dời nội dung sang trái 5mm (0.5cm): Trái 11mm, Phải 21mm */
  padding: 7mm 21mm 2mm 11mm !important; 
  page-break-inside: avoid; /* Ép không bao giờ nhảy trang */
  font-family: "Times New Roman", Times, serif !important;
}

/* 3. CÁCH LY VÙNG IN TUYỆT ĐỐI */
@media print {
  body * { visibility: hidden; }
  #print-section, #print-section * { visibility: visible; }
  #print-section {
    position: absolute; left: 0; top: 0; width: 100%;
    color: #000000 !important;
    background: transparent !important;
    -webkit-print-color-adjust: exact !important;
  }
}

/* 4. ÉP NÉT KIM ĐEN ĐẬM 1PX - KHÔNG DÙNG NỀN MÀU */
table.p-table th, table.p-table td {
